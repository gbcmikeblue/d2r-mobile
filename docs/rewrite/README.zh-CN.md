> 与 `docs/` 下那批**项目通用 / 旧路径**的文档分开（`ANDROID_PLAN` / `ANDROID_PROGRESS` / `CROSS_MACHINE` /

## 两分钟定位（为什么会有这个文件夹）

iOS 那边的图形层靠平台白拿了三件东西：**指针即缓冲**、**写完即可见**、**小提交便宜**。
这套代码搬到 Vulkan 上时默认这三件还在，但它们**都不存在** ⇒ 五个症状（画面全零 / 每轮约 10 秒 GPU 停摆 /
设备丢失 / 第二台启动即停在内存换轨 / AHB 把内核带 panic）是**同一个地基在五个位置上的开裂**，不是五个待排的 bug。

新路径就是把这三件事在 Vulkan 上**显式买回来**：
**影子内存 + 分块后备资源**（池永远是普通内存，GPU 用另一份）→ **脏记账 + 显式屏障 + 上传/回读窗口**
→ **帧批提交 + 有界在飞（删掉 `vkQueueWaitIdle`）** → **绑定以 SPIR-V 反射为唯一真源**。
