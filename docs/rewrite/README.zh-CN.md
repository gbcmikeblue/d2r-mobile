- **设计、规格、里程碑、工具清单、提示词**：已写完（都在本文件夹）；**新路径的游戏路径代码一行未动**。
- **里程碑**：**N0 已完成**（2026-10-16）—— 自证探针 `dm/android/vk2/vk2_probe.c` 在第一台真机跑了四轮
  （三轮完整、结果一致），四个常数各有真机读数：**块大小 960 MB**（纸面上限 = `maxMemoryAllocationSize` 1024 MB，
  由"1088 MB 失败 / 1024 MB 成功"证明）、**脏位图粒度 4 KiB 起步**、**`VK2_INFLIGHT` 3 起步**、
  **暂存环 16 MiB 起步**（一池全搬一遍 4096 MB ≈ 160 ms）。**只问不接管**：没动回放层、没写 `vk2_*`、没引入开关。
  **下一个是 N1**（影子 + 分块后备 + 地址反查，判据 G3）；N1~N6 未开工。
- **设备**：**第一台**（Adreno 830，`8b1f1e50`）是主战场；**第二台**（Mali-G610 MC6，`VC9TGM45MNJB8TSG`）
  **暂停到 N5**，别在它上面跑任何会走"内存换轨 / AHB"的动作（已验证会把内核带 panic）。
- **旧路**：全部保留、随时可退（`DM_GFX2` 缺省关；旧提交里 `DM_GFX_LEGACY` 的位留到 N6 才谈删）。

## 两分钟定位（为什么会有这个文件夹）

iOS 那边的图形层靠平台白拿了三件东西：**指针即缓冲**、**写完即可见**、**小提交便宜**。
这套代码搬到 Vulkan 上时默认这三件还在，但它们**都不存在** ⇒ 五个症状（画面全零 / 每轮约 10 秒 GPU 停摆 /
设备丢失 / 第二台启动即停在内存换轨 / AHB 把内核带 panic）是**同一个地基在五个位置上的开裂**，不是五个待排的 bug。

新路径就是把这三件事在 Vulkan 上**显式买回来**：
**影子内存 + 分块后备资源**（池永远是普通内存，GPU 用另一份）→ **脏记账 + 显式屏障 + 上传/回读窗口**
→ **帧批提交 + 有界在飞（删掉 `vkQueueWaitIdle`）** → **绑定以 SPIR-V 反射为唯一真源**。
